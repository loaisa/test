PostLearn - Платформа для создания постов
Описание проекта
PostLearn - это платформа для публикации и обмена статьями. Проект представляет собой веб-приложение с аутентификацией пользователей, возможностью создания и взаимодействия с контентом. Платформа позволяет пользователям писать статьи, просматривать публикации других авторов, оценивать их с помощью лайков и оставлять комментарии.
Технологический стек
Frontend:
React - библиотека для создания пользовательских интерфейсов
TypeScript - типизация кода для повышения надежности
Redux Toolkit - управление состоянием приложения
React Router - навигация между страницами
Material UI / https://mui.com/material-ui/- компонентная библиотека с готовыми UI-элементами
Axios - работа с HTTP-запросами
React Hook Form - управление формами
Backend:
Node.js - серверная платформа
Express - веб-фреймворк для создания API
MongoDB/Mongoose -база данных и для работы с MongoDB 
JWT - аутентификация на основе токенов
Cloudinary https://cloudinary.com/ - облачное хранилище для изображений
